# ChamthiQM

App chấm trắc nghiệm theo cấu trúc đề thi tốt nghiệp THPT từ 2025: quét phiếu bằng camera điện thoại, có điểm ngay, xuất bảng điểm Excel, mã QR đáp án và mã QR tra điểm cho học sinh.

- **Cài trên Android:** tải file `ChamThi.apk` ở nhánh `apk` của kho này (mở nhánh apk → bấm ChamThi.apk → Download raw / Tải xuống), mở file để cài.
- **Dùng trên web:** bật GitHub Pages cho nhánh `webapp` (Settings → Pages → Branch: webapp / root). App chạy ở `https://hatthi32.github.io/CHAMTHI-TN/`.

Mỗi lần cập nhật `index.html` trên nhánh `webapp`, GitHub Actions tự build lại APK.
